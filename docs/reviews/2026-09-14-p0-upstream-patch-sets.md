# Upstream patch sets for the P0 C++ findings

Seven local branches on dax carry the reviewed OpenMS4 Core fixes and their follow-up tests onto upstream OpenMS `develop` (3befd8ed77), one per area. Each was ported, reviewed, polished and verified again; all seven are marked ready for owner review. Nothing is pushed and no pull request exists. CPP-042 is not included (later cycle).

- **Clone:** `/scratch/kohlbach/openms-upstream-p0` on dax; branches `p0/<area>`; worktrees and build directories under `/scratch/kohlbach/openms-upstream-p0-wt/`.
- **Patch series:** `/scratch/kohlbach/openms-upstream-p0-wt/patches/<area>/` (`git format-patch` output).
- **Core counterpart:** `codex/p0-<area>` in `/scratch/kohlbach/openms4-p0`, merged into `codex/p0-followups` on OpenMS4-core. Code and test changes made during polishing were mirrored there as new commits.
- Every touched file was byte-identical between upstream `develop` and `core-v4.0.0-ci.2` when the branches were built.

## Decisions (accepted 14 September 2026)

- **CPP-166:** the empty-block MGF test stays next to the new two-block test, as implemented.
